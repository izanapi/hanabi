# HANABI — 音の図譜

スマートフォン縦画面の生成楽器。画面に触れて育て、離すと花火が開き、低いうねり・倍音・揺れる金属音が数秒かけてこぼれます。残光の外周をなぞると音が再び生まれます。複数指に対応。長押しは6秒で開花します。

特定の曲を演奏する鍵盤ではなく、一つの操作から音の時間変化を作る楽器です。Fを中心とした音階、非同期の発音、音ごとに異なる包絡と倍音で調和と偶然を両立します。

## 起動

ビルド不要。index.htmlをブラウザで開くか、`python3 -m http.server 8000` を実行してlocalhost:8000へ。音声は最初の操作で開始します。キーボードでは演奏面にフォーカスしてSpaceを押し、離します。

GitHub Pagesでは main / root を公開元に指定できます。公開設定は別途必要です。

## 制作方針

墨色、金色から青緑の細い放射線、標本図のような余白。音と視覚は同じ花火の寿命に従います。グリッドやBPMは導入しません。外部ライブラリ・音源・通信なし。音声はWeb Audioで合成。非表示時は音声と発音待ちを停止します。
