# HANABI — 音の図譜

スマートフォンを両手で持って奏でる生成楽器。最初から一つの大きな花火が開いており、二本の親指で同じ花火の音と光を変えます。指を離しても花火は消えず、音だけが余韻へ戻ります。

## 演奏

- 左半分に触れると持続音。上へ動かすと音が高く、中央へ寄せると強くなります。
- 右半分に触れるときらめく音。上へ動かすと明るく、中央へ寄せると音の間隔が細かくなります。
- 両手で触れると持続音ときらめきが重なり、花火全体が明るくなります。
- 指が画面中央を越えても、触れ始めた側の役割を保ちます。
- ECHO / HALL / VOLUME と消音ボタンで響きと音量を調節できます。

## 起動

ビルド不要。`index.html` をブラウザで開くか、`python3 -m http.server 8000` を実行して localhost:8000 へ。音声は最初の操作で開始します。

キーボードでは演奏面にフォーカスし、Fで左手、Jで右手、Spaceで両手の演奏。押しながら上下キーで音高、左右キーで音色を調節できます。マウスは片手ずつの操作に対応します。

GitHub Pagesでは main / root を公開元に指定できます。公開設定は別途必要です。

## 制作方針

墨色、金色から青緑の細い放射線。音高はFを中心とした音階に沿い、持続音は滑らかに変化します。外部ライブラリ・音源・通信なし。Web Audioによる合成音。非表示・フォーカス喪失時には演奏を解除して音声を停止し、次の演奏操作で再開します。動きを減らす設定では装飾の回転や粒の移動を抑えます。

## 確認

JavaScript構文と模擬DOM / AudioContextによる初期描画、二本指、音高変更、中央を越えた指の役割維持、指の解除・キャンセル、キーボード、音声の停止・再開を確認済み。スマートフォン実機での音質・同時タッチの確認は別途必要です。
